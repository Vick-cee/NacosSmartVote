A simple and secure online voting platform built for the Faculty of Computing, Kaduna State University.
It enables students to vote digitally in faculty and departmental elections with transparency and ease.

🚀 Features

Secure user login

Admin panel for managing candidates & positions

Real-time vote counting

Mobile-friendly interface

Prevents duplicate voting

🛠️ Tech Stack:
Frontend: HTML/CSS/JS
Backend: Node.js

📦 Setup
git clone https://github.com/Vick-cee/NacosSmartVote.git
cd your-repo
# install dependencies if applicable

📘 Usage

Admin creates election & adds candidates

Students log in and cast their vote

System displays real-time results
